# CS 开箱统计助手(Chrome / Edge 浏览器插件)

自动扫描 Steam 库存历史,统计你的 **CS2 / CS:GO 开箱、炼金(升级/汰换合约)、开胶囊** 次数,支持按月汇总、分类复核修正与 CSV 导出。数据只保存在本机浏览器中,不上传任何服务器。

## 安装(Chrome 与 Edge 步骤相同)

1. 下载/解压本目录(文件夹名 `cs-inventory-counter`)。
2. 打开浏览器扩展管理页:
   - Chrome:地址栏输入 `chrome://extensions`
   - Edge:地址栏输入 `edge://extensions`
3. 打开右上角「开发者模式」开关。
4. 点击「加载已解压的扩展程序」(Edge 为「加载解压缩的扩展」),选择本目录。
5. 工具栏出现扩展图标即安装成功。建议点击图标右侧的「固定」,方便随时查看。

## 使用

1. 点击工具栏上的扩展图标,在弹窗中点「开始/继续扫描」。
2. 插件会自动打开你的 [Steam 库存历史](https://steamcommunity.com/my/inventoryhistory/) 页面并开始扫描;页面右下角会出现悬浮面板,实时显示进度与计数,也可直接在面板上点「开始扫描/停止」。
3. 扫描完成后,在弹窗中查看:
   - **统计**:开箱 / 炼金 / 开胶囊 总数、按月汇总表、最近记录;可导出 CSV。
   - **复核**:对分类有误的记录手动修正(如"疑似炼金"提示项),取消勾选「计入」可把某条记录排除出统计。
4. 以后再扫描只会补充新增记录,已修正的分类不会被覆盖。

## 统计口径说明

- 分类依据是 Steam 库存历史里每条记录的「事件说明」文字,同时支持简体中文、繁体中文与英文界面(如「在《反恐精英2》中开箱」「Unboxed in Counter-Strike 2」「升级合约 / Trade Up Contract」「打开贴纸胶囊 / Opened a sticker capsule」)。
- 社区市场买卖、玩家交易、游戏掉落等记录会自动归为「其他」,不计入三类统计。
- 若某条记录说明缺失,会进入「待复核」;移除多件+获得 1 件的记录会提示「疑似炼金」。
- 炼金如果在 Steam 历史中显示为两条记录(移除 10 件 + 获得 1 件),统计会按可识别的说明文字归类,无法识别时请在「复核」页确认。

## 常见问题

- **提示"未发现历史记录行"**:请确认已登录 Steam 且当前页是你自己的库存历史页(`.../inventoryhistory`);别人的历史页是私密的,无法访问。
- **扫描很久不停**:历史记录很多时属正常现象,可随时点「停止」,进度已保存,下次继续。
- **界面是英文**:分类规则已兼容英文说明;如仍有大量误分类,请到「复核」页修正,并欢迎反馈说明原文以改进规则。
- **统计数量与预期不符**:请先到「复核」页查看「待复核」记录;市场买卖的箱子、胶囊本身不会被计为开箱。

## 目录结构

```
cs-inventory-counter/
├── manifest.json          # MV3 清单(Chrome/Edge 通用)
├── content/
│   ├── parser.js          # 纯函数解析器:分类、日期解析、说明提取(中英双语)
│   ├── content.js         # 库存历史页注入:悬浮面板、自动滚动扫描、存储合并
│   └── content.css
├── popup/
│   ├── popup.html         # 弹窗:统计 / 复核 / CSV 导出
│   ├── popup.css
│   └── popup.js
├── icons/                 # 16/32/48/128 图标
├── test/parse-test.cjs    # 解析器单元测试(node test/parse-test.cjs)
└── tools/make-icons.js    # 图标生成脚本(node tools/make-icons.js)
```

## 隐私

插件仅在你打开 Steam 库存历史页时读取页面内容,统计结果保存在浏览器本地存储(`chrome.storage.local`)中,不收集、不上传任何个人信息。
